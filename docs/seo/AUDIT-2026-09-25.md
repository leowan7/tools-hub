# SEO audit — tools.ranomics.com, 2026-09-25

Method: every row below was fetched LIVE from https://tools.ranomics.com on
2026-09-25 by a stdlib script (urllib + html.parser, redirects not followed,
User-Agent `Mozilla/5.0 (seo-audit)`). Sitemap and robots.txt were fetched in
the same run. Anything not fetched is marked UNVERIFIED.

Caveats on the columns:

- **Title** is the first `<title>` in the document. `/` and `/tools` also carry
  inline-SVG `<title>` elements in the body; those are icon labels, not page titles.
- **Links out / in** counts internal paths linked from `<a href>`. "In" is counted
  only among the 46 audited URLs, not a full-site crawl, so it is a floor.
- **HTML KB** is the HTML document alone, not CSS/JS/images/fonts. Total page
  weight including assets is UNVERIFIED.
- No page returned an `X-Robots-Tag` header, and every 200 page carries
  `<meta name="robots" content="index,follow">`.
- robots.txt: `Allow: /` plus explicit Disallows for per-user and auth paths
  (`/account`, `/jobs`, `/runs`, `/login`, `/api/`, …). Nothing public is blocked.
  It declares `Sitemap: https://tools.ranomics.com/sitemap.xml`.
- Sitemap had 39 `<loc>` entries.

## Top findings

1. **Four free, public tool pages were missing from the sitemap:** `/prep`,
   `/developability`, `/library-planner` and Epitope Scout's canonical URL
   `/scout/`. FIXED in this PR.
2. **The sitemap listed `/scout`, which 308-redirects to `/scout/`** (the page's own
   canonical). A sitemap should list the canonical URL, not a redirect. FIXED.
3. **Tool pages show dollar figures to anonymous visitors.** Live `/tools/bindcraft`
   shows "cost $2.04" for a recorded run and a `$6.30` estimate; `/tools/af2` and
   `/tools/boltzgen` show the same pattern; every tool page and `/pricing` say "New
   accounts start with a $20 wallet balance"; `/pricing` states a $20 minimum
   top-up and a $1,000 default monthly cap. No per-GPU-hour rate was found on
   `/pricing` or `/tools/bindcraft` (grep for "per hour", "/hr", "gpu hour").
   Whether these fall under the 2026-09-25 no-prices decision is **Leo's call**;
   NOT changed here. (The worked-example cost lines sit in the component another
   worker is editing.) Inline `<script>` comments also ship in the page source
   (e.g. "a bare Math.ceil turns $0.07 into $0.08").
4. **Tool-page `<h1>` is the bare tool name** ("BindCraft", "AlphaFold2"). The
   title and description carry "<Tool> Online"; the H1 carries no search phrase.
   The H1 lives in `templates/tools/_form_hero.html`, which is out of scope for this
   PR (another worker is editing it). NOT changed.
5. **Tool-page meta descriptions run 230–336 characters.** Each opens "Run <Tool>
   online on a dedicated GPU through your browser. No install, no local CUDA." so the
   searched name survives SERP truncation, but the differentiator sentence is cut.
   How many characters Google displays is UNVERIFIED here. NOT changed.

Other findings:

- **SoftwareApplication JSON-LD is not rich-result eligible.** Google's
  SoftwareApplication doc (fetched 2026-09-25,
  developers.google.com/search/docs/appearance/structured-data/software-app) lists
  `name`, `offers.price` and one of `aggregateRating` / `review` as required. The tool
  pages have no `offers` (adding a price conflicts with the no-prices decision) and no
  ratings. The JSON still parses and describes the page. NOT changed.
- **The four free tool pages had only Organization JSON-LD.** FIXED: each now emits a
  WebApplication block whose description is the page's own meta description.
- **`/prep` title was "Target prep — Ranomics Tools" (28 chars), with no search phrase.**
  FIXED: "Protein Target Prep for Binder Design | Ranomics Tools".
- **`/tools` description opened "Free GPU-backed protein design tools"**, but GPU runs are
  billed to the wallet (the code dropped "Free" from tool titles for that reason; see
  the `_PREVIEW_TITLE_PHRASES` comment in blueprints/tools.py). FIXED: "Free" removed.
  Its tool list also omits five of the fourteen tools (Boltz-2, IgGM, OpenDDE, Proteina-Complexa,
  ESMFold2 design). NOT changed.
- **`/pricing` title "Pricing | Wallet cap, unlimited design" lacks the brand.** NOT changed.
- **Each tool is described by SoftwareApplication JSON-LD on two URLs:** `/tools/<slug>` and
  `/help/tools/<slug>`. Whether search engines treat that as a conflict is UNVERIFIED. NOT changed.
- **`/library-planner` has zero inbound links among the audited pages.** The sitemap now lists it.
  Adding an in-page link is NOT done.
- **HTML weight:** `/tools/boltzgen` 374 KB, `/tools/esmfold` 349 KB and
  `/tools/proteina` 227 KB of HTML before any assets. NOT changed.
- **Help-guide titles all follow "How to run <Tool> guide | Ranomics Tools"** and the descriptions
  share one template sentence. They are not exact duplicates (the tool name differs), and no two
  audited pages share an identical title or description.
- `/scout/feasibility` 302s to login and `/scout/example` returns JSON; neither belongs in the
  sitemap, and neither is listed.
- `/tools/proteinmpnn` 301s to `/tools/mpnn` and is correctly absent from the sitemap.

## What this PR changes

- `blueprints/public.py` sitemap: `/scout` becomes `/scout/`; adds `/prep`, `/developability`
  and `/library-planner`.
- `cron/indexnow_ping.py`: the same `/scout/` fix, and adds `/prep`.
- `templates/components/_webapp_ld.html` (new): WebApplication JSON-LD macro. It is used
  by `/prep`, `/scout/`, `/developability` and `/library-planner`, with each page's
  existing meta description as the JSON-LD description (no new copy).
- `templates/prep.html`: new title.
- `templates/tools/comparison.html`: "Free" removed from the meta description.
- `tests/test_seo_sitemap.py`: every sitemap `<loc>` must answer an anonymous GET with 200;
  the four free pages must be listed and must carry exactly one WebApplication block whose
  description matches the meta description.
