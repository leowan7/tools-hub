{# submit_cta.html — primary submit button with double-submit guard. Wires a click handler that disables the submit button after the first click so a second click during dispatch cannot double-submit. Closes Bug B (job-submit idempotency 2026-04-29 — accidental double-submits at pilot tier). Anonymous visitors reach the same form (the GET on /tools/ is public); only Submit is gated. They get a sign-in link in place of the button, so no submit control exists on the page at all and submit_cta_script() no-ops on the missing [data-submit-cta]. Auth state comes from ``viewer_is_signed_in()`` (a jinja GLOBAL registered in app.py) rather than a context var, because these macros are imported WITHOUT ``with context`` by all 14 tool forms and so cannot see the caller's context. Callers may still override with ``authenticated=``; the default of ``none`` means "ask the session", which is the same key blueprints/tools.py branches on. Usage: {% from "components/submit_cta.html" import submit_cta, submit_cta_script %} {{ submit_cta(label="Submit run") }} ... {{ submit_cta_script() }} #} {% macro submit_cta(label="Submit run", authenticated=none) %} {% set _auth = viewer_is_signed_in() if authenticated is none else authenticated %} {% if _auth %} {% else %} {# Same words as the 13 forms that hand-roll their submit button. #} {% include "components/_signin_cta.html" %} {% endif %} {% endmacro %} {% macro submit_cta_script() %} {% endmacro %}
