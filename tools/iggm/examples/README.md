# IgGM examples

Load Example chips are retired platform-wide (no one should spend GPU on an
example), so no example inputs are bundled here and the form renders no chip.

The canary runs exercise IgGM's own repo-bundled public complexes **Modal-side**
from the cloned IgGM repo (`examples/pdb.files.native/...`), not from this
directory:

- `8iv5_A_B_G` — I-1 smoke (complex prediction + the README epitope list); the
  pass criterion is that the predicted antibody contacts the requested epitope.
- `8hpu_M_N_A` — I-2 CDR design and I-3 affinity maturation.

This directory is intentionally empty of inputs.
