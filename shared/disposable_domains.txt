# Disposable / throwaway email domains
#
# Loaded by shared/email_domain.py at import time. One domain per line.
# Comments (# ...) and blank lines ignored. Matching is case-insensitive
# on the full registered domain (e.g. "mail.tm" matches an email like
# joe@mail.tm).
#
# This is a curated subset (~250 entries) covering the dominant
# disposable services that we see in the wild. Coverage is high on the
# common bot/junk flow; long-tail throwaway providers may slip through.
# When that happens, add the offender here and redeploy — that is
# cheaper than auto-fetching a remote list at runtime.
#
# Source reference: github.com/disposable-email-domains/disposable-email-domains
# (refresh quarterly by hand)
